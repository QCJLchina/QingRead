# 轻阅 / QingRead v3

基于 Tauri 2 + React 18 + Rust 的轻量级电子书阅读器，支持 EPUB 和 TXT 格式。产品名为 **轻阅 / QingRead**。

## v3.0.1 主要更新

修一个会影响「外放」观感的问题：仓库与发布页此前未声明许可证。

- **采用 MIT 许可证**：新增 LICENSE，package.json 与 Cargo.toml 声明 `license`，README 许可章节改为指向 LICENSE。此前未声明许可证时，他人没有使用、修改与分发的授权。

此外本版重新打包发布，使安装包与绿色版内含的文档和许可证信息与仓库一致。

## v3.0.0 主要更新

- **统一改名**：产品确定为「轻阅 / QingRead」，界面、窗口标题、托盘提示、安装器、可执行文件与包名全部一致；应用标识、默认数据目录、WebDAV 远端目录和系统凭据服务名刻意保留旧值，升级后书架、进度、自定义目录和同步密码都不受影响。
- **分页阅读**：单页横向排版，底栏固定「上一页 / 章内页码 / 下一页」，翻到章末自动进入下一章首页。支持方向键、PageUp / PageDown、空格 / Shift+空格和滚轮翻页，并过滤触控板惯性。
- **稳定阅读位置**：进度改为保存正文锚点（文本节点路径、字符偏移、附近文本片段、章内比例），改动窗口比例、字号、行距，开合目录或切换阅读方式后仍停在原来的那句话；旧版页码进度会被读取并自动转换。
- **自由窗口比例**：新增标准阅读、办公窄栏、底部横条、迷你阅读四种预设，支持自由宽高与锁定当前比例，最小 320×200，上限受当前显示器工作区限制。
- **办公低干扰**：中性窗口标题「随手记」、可选置顶、一键遮挡正文；全局快捷键 `Ctrl+Alt+H` 隐藏 / 恢复窗口，隐藏前会确保托盘恢复入口可用。
- **架构整理**：Tauri 调用收敛到类型化接口层；阅读页拆分为阅读会话、排版引擎、输入控制、窗口服务四项职责；切换章节保留旧内容直至新内容就绪，进度按书籍串行保存。
- **构建脚本**：新增 `build.ps1` 一键打包，路径与版本号均从项目自身推导，不再依赖固定盘符或写死的版本字面量。

## 安装与使用

### 系统要求

- Windows 10 22H2+ / Windows 11（已预装 WebView2 Runtime）
- 如提示缺少 WebView2：https://aka.ms/webview2

### 方式一：NSIS 安装器（推荐）

1. 双击 `QingRead_3.0.1_x64-setup.exe`
2. 按向导安装
3. 从开始菜单或桌面快捷方式启动

安装目录默认 `C:\Program Files\QingRead\`，数据存储在 `%APPDATA%\EpubReader\`（沿用旧目录名，升级后书架与进度不丢失）。

### 方式二：绿色版（免安装）

1. 解压 `QingRead_3.0.1_x64-portable.zip` 到任意目录
2. 双击其中的 `qingread.exe` 运行，首次启动会在 `%APPDATA%\EpubReader\` 创建数据目录
3. 想换地方就整个目录挪走，不写注册表，卸载时直接删目录

## 使用方法

### 添加书籍

- **拖入**：在书架页面中央的虚线区域拖入 `.epub` 或 `.txt` 文件
- **浏览**：点击虚线区域中的「浏览文件」按钮选择文件
- **命令行**：`qingread.exe "D:\books\novel.epub"`

### 阅读

- **分页阅读**：底栏箭头、← →、PageUp / PageDown、空格 / Shift+空格、滚轮均可翻页；翻到章末自动衔接下一章
- **滚动阅读**：自然滚动，底栏箭头按一屏移动；可在阅读设置里随时切换
- **目录**：宽窗口固定在左侧，窗口变窄后改为浮层；翻章操作集中在目录里
- **搜索**：输入关键词跨章节搜索；点结果跳到命中位置并高亮，底栏出现「返回跳转前位置」
- **低干扰模式**：窗口标题变为中性的「随手记」，隐藏装饰背景，精简工具栏
- **遮挡正文**：一键换成中性页面，点「恢复阅读」回到原处
- **隐藏窗口**：`Ctrl+Alt+H` 全局快捷键或托盘图标隐藏 / 恢复，隐藏前后阅读位置不变
- **返回书架**：点击工具栏「书架」按钮（会先保存当前进度）
- **Esc**：依次关闭当前面板、收起目录；没有面板时留在阅读页，不会误退到书架

### 窗口形态

阅读页的「窗口尺寸」面板提供四种预设，尺寸是窗口客户区逻辑像素：

| 预设 | 尺寸 | 说明 |
|------|------|------|
| 标准阅读 | 940 × 610 | 完整工具栏，目录可以固定在左侧 |
| 办公窄栏 | 360 × 610 | 单栏正文，目录与设置改为浮层 |
| 底部横条 | 760 × 270 | 适合贴在屏幕底部 |
| 迷你阅读 | 340 × 230 | 最小占用，保留翻页与退出 |

也可以直接输入任意宽高；最小 320 × 200，上限受当前显示器工作区限制。
窗口尺寸、位置、置顶、快捷键都记在 `window.json` 里，下次启动自动恢复；
多显示器拔插后窗口会被拉回可见范围，不会消失在屏幕外。

### 阅读进度

- 保存的是**正文里的位置**（字符锚点），而不是页码
- 调整窗口比例、字号、行距或切换分页 / 滚动后，重新排版仍停在同一句话
- 重新打开书本回到上次位置；旧版本保存的页码进度会被读取并转换为锚点
- 底栏显示当前章节和整书估算进度（章节等权 + 章内位置）

### 设置

阅读排版在阅读页的「阅读设置」面板里；应用级设置点击顶部导航栏「设置」进入：

| 位置 | 设置项 | 说明 |
|------|--------|------|
| 阅读设置 | 阅读方式 | 分页 / 滚动 |
| 阅读设置 | 字号 | 12-32px |
| 阅读设置 | 行距 | 1.2-3.0 |
| 阅读设置 | 字体 | 系统 / 宋体 / 黑体 / 等宽 |
| 阅读设置 | 正文栏宽 | 限制每行长度，避免窗口拉宽后一行太长 |
| 阅读设置 | 页边距 | 8-80px |
| 阅读设置 | 配色 | 明亮 / 暗黑 / 羊皮纸 / 护眼绿 |
| 窗口尺寸 | 预设与自定义宽高、置顶、低干扰、工具栏自动收起、失焦遮挡、快捷键 | |
| 设置 | 自定义背景 | 上传图片作为阅读背景 |
| 设置 | 关闭行为 | 直接退出 或 最小化到托盘 |
| 设置 | 数据目录 | 更改书籍/进度/设置存储位置 |
| 设置 | 网络同步 | WebDAV |
| 设置 | 关于 | 版本号 |

## 数据存储

```
默认数据目录：
├── books/           # 电子书源文件
├── covers/          # 封面图片缓存
├── progress/        # 阅读进度（章节 + 正文字符锚点）
├── library.json     # 书架列表
├── settings.json    # 用户设置（含阅读排版）
└── window.json      # 本机窗口形态与低干扰偏好（不参与同步）
```

- 默认：`%APPDATA%\EpubReader\`
- 可在「设置 → 数据目录」中切换到其他位置
- 迁移到新电脑：复制整个 `data/` 目录即可

## TXT 章节识别

解析器自动识别以下章节标记：

- **中文模式**：`第N章`、`第N回`、`第N节`、`第N卷`、`第N集`、`第N篇`
- **数字格式**：阿拉伯数字（123...）、中文数字（一二三...）
- **特殊标记**：序章、楔子、终章、尾声、后记、前言、引子、番外
- **英文模式**：`Chapter N`、`CHAPTER N`

如无章节标记，自动按约 5 万字符分章。

## 常见问题

**Q: 打开 exe 提示缺少 WebView2？**
A: Windows 10 1809 以下需手动安装：https://aka.ms/webview2

**Q: 拖入文件没反应？**
A: 需要拖到书架页面中央的虚线框区域上方，不要拖到其他位置。

**Q: EPUB 中文乱码？**
A: 本应用按 UTF-8 解析 EPUB 内容；如仍乱码请检查 EPUB 源文件编码。

**Q: TXT 章节识别不准？**
A: 确认章节标题以"第N章"等格式开头。不规范的标题会触发按字数自动分章。

**Q: 图片不显示？**
A: EPUB 图片通过受限本地资源协议按需读取；单个资源超过 64 MB 会被拒绝加载。

**Q: 数据怎么迁移？**
A: 复制 `data/` 目录到新电脑，在「设置 → 数据目录」指向该目录后重启应用。

## 命名与兼容

产品已从 EpubReader 改名为 **轻阅 / QingRead**：界面、窗口标题、托盘提示、安装器、
可执行文件（qingread.exe）和包名都已统一。

以下几处刻意保留旧标识，改名会让升级后的用户丢数据或丢配置：

| 位置 | 值 | 原因 |
|------|----|------|
| 应用标识 | com.epubreader.app | 与已安装版本保持一致 |
| 默认数据目录 | %APPDATA%\EpubReader\ | 旧版书架、进度、自定义背景都在这里 |
| WebDAV 默认远端目录 | EpubReader | 已同步过的用户能继续看到自己的书 |
| 系统凭据服务名 | EpubReader WebDAV | 保存的密码不用重新输入 |

安装器会以新名字安装，因此控制面板里可能同时存在旧的 EpubReader 条目，
手动卸载旧版本即可，数据目录是共用的。

## 开发

```powershell
# 安装依赖
npm install

# 开发模式（前端热重载）
npm run tauri dev

# 生产构建（前端 + Rust release + NSIS 安装器）
npm run tauri build

# 或者用脚本一键打包：自动配好工具链，并在结束时打印产物路径
powershell -ExecutionPolicy Bypass -File .\build.ps1

# 产物位置
src-tauri\target\release\qingread.exe                                # 绿色版可执行文件
src-tauri\target\release\bundle\nsis\QingRead_3.0.1_x64-setup.exe  # NSIS 安装器
```

`build.ps1` 优先使用项目内 `.tools\cargo-home` 的 Rust 工具链（若存在），否则回退到 PATH 上的 cargo；两者都没有时会明确报错。

如果链接阶段报 `cannot find -lwindows.*` 或找不到 `libstd-*.rlib`，通常是 Rust 工具链装在含非 ASCII 字符的路径下（例如中文用户名），MinGW 的 `ld` 读不了这类路径。把工具链放到纯 ASCII 目录即可，`build.ps1` 的 `.tools` 方案就是为此准备的。

注意：国内网络需配置 Rust crates 镜像，否则首次 `cargo build` 会卡住：
```toml
# ~/.cargo/config.toml
[source.crates-io]
replace-with = "ustc"
[source.ustc]
registry = "sparse+https://mirrors.ustc.edu.cn/crates.io-index/"
```

## 发布

推 `v*` 标签会触发 GitHub Actions 流水线（`.github/workflows/release.yml`）：
在 windows-latest 上装 Node 24 与 Rust、跑前端与 Rust 测试、执行 `npm run tauri build`，
然后创建 **draft release** 并附上两个产物。流水线不签名，也不需要任何 Secrets。

| 产物 | 说明 |
|------|------|
| `QingRead_<版本>_x64-setup.exe` | NSIS 安装器 |
| `QingRead_<版本>_x64-portable.zip` | 绿色版压缩包，内含 `qingread.exe` |

发布步骤：先把版本号改好并提交（`package.json` 与 `src-tauri/tauri.conf.json` 必须一致，
流水线会校验），再去 Actions 页手动 Run workflow 干跑一次确认构建通过，最后打标签：

```powershell
git tag -a v3.0.1 -m "轻阅 v3.0.1"
git push origin v3.0.1
```

标签必须与版本号一致（`v3.0.1` 对应 `3.0.1`），对不上流水线会直接失败。
流水线只创建 draft release，release notes 需要你在网页上补充后再手动 Publish。
